# xxqz 的 C++ 版本

此目录是仓库中 `xxqz/main.py` 的 C++20 移植版，使用官方 `helper.hpp` 接口。它按原方案重建了状态、寻路、候选评估和分裂流程；由于 Python 和 C++ helper 的对象接口不同，代码不是逐行翻译，随机或同分候选的逐动作结果也不保证完全一致：

- 每条龙维护独立的可见地图、珍珠位置和珍珠倒计时记忆；
- 优先追踪当前视野内珍珠，其次追踪记忆中的珍珠和近期生成点；
- 避开海带、可见龙身和已知自身身体；
- 局部 BFS（深度 12、最多 220 个节点）寻找珍珠和探索目标；
- 逐步模拟移动的碰撞、尾部变化、吃珠和冲刺支付规则；
- 记录可见边和传送门端点，对未知传送门采取保守策略；
- 根据邻域开放程度、珍珠、倒计时和探索价值给候选移动打分，并识别局部死胡同；
- 在地图较小且长度、人口满足条件时分裂；
- 无合法候选时使用保底移动。

由于 Python 原版依赖运行时字典和异常回退，C++ 版将这些部分改写为显式结构。当前决策器和 Python 原版一样通常输出一步移动；多步动作的规则被用于模拟和合法性评估。传送门的未知出口采取保守跳过策略。

运行：

```bash
CXX=clang++ unswbc run maps_BeforeSprinter/arena.map xxqz_cpp SW_Champion \
  -o artifacts/xxqz_cpp_vs_champion.replay
```
