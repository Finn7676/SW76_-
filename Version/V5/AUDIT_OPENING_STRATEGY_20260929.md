# 2026-09-29 开局均匀铺图与短龙珍珠逃生

基线：`1f6b722b5813c26cc27455baac2f0a485b352f8f`。

开局第 0–2 轮首次行动的龙恢复按自己的出生朝向选择穿越中心或反向绕边。已移除视野内队友朝向相同、方向不明确时按 ID 分配“中心→反向→中心”的规则；同向和方向不明确的队友均不再触发路线重分配。其余任务解除、传送门和珍珠逃生改动保留。

反向绕边任务仅在进入实际出生点的中心对称点周围 3×3 区域时完成。直穿中心任务分别记住横、纵中轴线的穿越进度；先后穿越均可，完成一条后仍继续任务。出生在中轴线上或沿中轴线移动不计作穿越；奇数尺寸地图上，必要时把直穿目标移到中轴线另一侧的一格，确保实际发生横向或纵向移动。普通移动及冲刺的连续路径可记录进度，地图边缘环绕和传送门跳跃不会计入穿越。

直穿路线采用经过地图内部的距离，绕边路线继续使用原有有向环绕距离。`bugnav.hpp` 未修改。既有封闭地图边缘改去中心、珍珠采集仲裁、未探索传送门选择及第 60 轮任务截止规则保留。传送门出口是开阔区域时解除开局任务；已确认封闭的小空间仍探索并返回，返回后保留原任务与穿越进度。

短龙逃生只针对出生时为 3–4 节、头部处于已确认死路的龙。需要尾部可见并有空出口，前方是完全可见、无分叉、最多三格连续珍珠的死路，且采集后至少达到 5 节；有敌人、人口不能再分裂或其他条件不成立时不启用。满足条件后吃完珍珠，再剥出恰好 3 节。该采集状态跨回合保留，最终动作被改道时取消。原本出生的长龙缩短后不能切入这项策略；前 20 轮其他受困情景仍连续 `SPLIT 2`，不要求尾部可逃。已有长度 2 龙采集资源袋后按收益可变长度分裂的策略也保留。

验证：9 组 C++ 回归全部通过；7 个协议回放通过 ASan/UBSan；出生朝向不受队友和 ID 分工影响、横纵穿越、出生在轴上、传送门与跨回合珍珠逃生回归也通过 ASan/UBSan。通用 V3 回归明确在第 60 轮后测试，避免把“出生在中心”误认为新规则下已完成铺图。

两个真实 WASM 引擎的定向角落场景分别从 3 节、4 节开始，动作均为 `MOVE W → MOVE N → SPLIT 3`。3 节子龙出生当轮行动，并在后两轮继续逃出；留在死路中的母龙随后死亡。这是按截图结构重建的受控场景，没有原截图完整回放，不能当作原局精确复现。

`dilemma`、`devil`、`big_empty` 各换边检查前 60 轮，共六场。执行错误、能分裂却无动作、自撞均为 0；存在战斗死亡和无法再分裂的小龙死亡。最高单回合 CPU points 为 6,704,369。这些检查验证行为与执行稳定性，不构成胜率或探索覆盖率对照统计。
