# V5 导航进展修复（2026-10-01）

Schooltime 为 60×40 地图，顶部北向接缝封闭，初始珍珠在 y=34–38。

两处问题：BugNav 只处理停在原格，未识别移动中的重复位置/朝向；普通探索算出了 BFS 前沿方向，但最终选步只奖励战斗和采集方向，探索方向容易在同分时被横走替代。

更新后的行为：

- 沿墙时记录位置和朝向，重复状态触发脱困。
- 绕圈涉及已观察到的封闭接缝时，本次目标在对应轴上暂用经过内侧的距离；另一轴保留有效的环绕路线。
- 脱困使用已知地形上的有限 BFS，最多 320 个节点、24 步，并保存完整绕行路线。新占用、第一步安全限制或实际动作偏离会使旧绕行路线失效。
- 普通探索给 BFS 方向加分；威胁等级、真实碰撞、队友保护和空间检查仍参与最终决定。

验证：

- 13 组 C++ 回归通过。新回归覆盖四个方向的封闭接缝、不同绕墙侧、真实身体移动、正常环绕、内墙绕行，以及顶端已探索条带向下探索。改前版本在同一新回归中失败。
- 导航回归与 7 个历史协议场景通过 AddressSanitizer/UndefinedBehaviorSanitizer。
- Schooltime，seed=7，双方均运行对应版本，原生引擎前 160 轮对照：最后 60 轮头部位于 y=0–3 的行动回合占比从 807/3494（23.1%）降为 616/4307（14.3%）；A 队已见格数从 1810 增至 2281，B 队从 1929 增至 1999。此记录衡量探索行为，不代表胜率。
- 正式 WASM 编译器与运行环境验证 Schooltime 前 100 轮，共 2625 次行动，无运行错误；最高单次计费为 6,386,253 points。

复现当前版本：

```sh
python3 -B verification/run_checks.py
python3 -B verification/schooltime_engine.py --rounds 160
python3 -B verification/schooltime_engine.py --mode wasm --rounds 100
```

地图默认读取 V5 相邻的 maps/schooltime.map，也可以使用 `--map` 指定路径。`--source` 可指定对照版本，`--output` 可保留逐回合记录，默认输出到 /tmp。
