# V5 声纳协作更新（2026-10-01）

## 消息

新消息均为 64 位：40 位载荷、8 位类型/队伍标记、16 位校验。
队伍标记位于类型字节最低位，发送者 ID 使用完整的 16 位，不截断。
标记和校验只验证协议格式，不认证发送者，也不证明内容真实。

| 消息 | 载荷（从低位到高位） | 含义 |
| --- | --- | --- |
| PORTAL_BUSY，F0/F1 | portal 13，sender 16，round 9，busy 1，保留 1 | 占用或释放该发送者的临时占用报告 |
| PORTAL_HOLD，FC/FD | portal 13，sender 16，round mod 64 为 6，direction half 1，length 4 | 头部恰好贴门时向该门发射，携带自身长度下限，请对面暂缓穿出 |
| PEARL_INTENT，F2/F3 | x/y 各 6，sender 16，round 9，ETA 3 | 下一颗珍珠；ETA 为本次动作后 1–4 个回合，0 取消 |
| PEARL_STATUS，F4/F5 | x/y 各 6，due 9，observed 9，state 2，保留 8 | 倒计时、观察到珍珠、已吃掉；due=511 表示未知 |
| ALLY_LENGTH，F8/F9 | sender 16，round 9，length 14，exact 1 | 本次动作后的自身长度；exact=0 表示下限，长度最大 16383 |
| RALLY_INTENT，F6/F7 | x/y 各 6，sender 16，round 9，direction 3 | 本次动作后的头部位置，预计下一步；direction=4 表示未知 |

原有 PORTAL_PAIR、探索 CLAIM、ENEMY、HISTORY 保留。旧末期长度 RALLY 仍可接收，新的通用长度包不再受末期门槛或 63 长度上限限制。
完整长度与行动位置分包，避免截断 ID 或完整长度字段。
等待包另外直接携带长度下限 `min(本次动作后长度, 15)`，2/3 可直接区分，15 表示至少 15；完整长度仍由 ALLY_LENGTH 广播。
传送门边提供方向轴，等待包只需记录 N/E 与 S/W 两个方向半区。等待包不被转发，只采用当轮或上一轮消息，6 位时间戳按该窗口还原；任意延迟 64 轮的外部重放不在该短期协议的时效保证内。
新的 FC/FD 与旧 FA/FB 格式分离，旧等待包不能触发紧急自杀。
协议尚未升级的输入保留旧 32 位发送；PROTOCOL 3 从下一回合开始提供新输入。

## 决策规则

- PROTOCOL 3 每轮预留一束广播自身长度，最多四束；没有等待通知时，穿门当回合三束发送占用、一束发送长度。引擎只在该动作存活后发射。
- 等待通知只由本次动作后存活的头部恰好贴着传送门边时触发，并沿该门方向定向发射。只是身体靠近门、头部离门一格或更远、未知落点，都不触发；无需知道配对门坐标。头部离开门口后停止续报。
- 通知按传送门 ID、发送者、入门方向保存，只暂停对面反方向的穿出；其他门与同一对门的另一方向不受该通知限制。发送当轮及下一轮有效，第二个后续回合失效；当前可见发送者头部已经离开该门边，也立即不再采用该通知。
- 收到有效等待包后，优先安全地在内部移动，检查普通移动及冲刺中的每次穿门。
- 当前头部在被通知的门边、发送者长度下限至少 2、没有其他安全内部移动路线时，长度 2/3 直接 `Action::suicide()`，避免穿出去撞队友；长度至少 4 且人数允许分裂、尾部有已知逃生格时，优先 `SPLIT (自身长度-2)`，头部留下长度 2，尾部子龙拿走其他段。头部下一轮仍满足受困条件才自杀。
- 这是紧急避撞，所有轮次可用，不受第 400 轮主动献祭门槛限制。另一条未解析的可行传送门使受困条件不确定，不据此主动自杀。无可逃尾部或无法分裂的长龙保留普通生存决策。
- 没有等待包、过期通知、异队消息或单独收到普通长度广播，都不触发该紧急自杀。NONE 会死亡，内部等待仍必须执行移动；主动避撞自杀使用明确的 SUICIDE 动作类型。
- 等待包占用对应门方向的声纳束，并在包内同时携带长度下限；完整长度包移到其他方向；四面都是门时每轮最多通知三面，轮换剩余一面给长度包。收到通知不代表发送者对区域作出门内/门外的全局分类：规则依据具体门边和穿门方向。
- 长度包含本次已知吃珍珠增量、冲刺消耗和分裂转出的长度；遇到未知格子或未知门落点时发送保守下限。NONE/自杀不发布存活长度。
- 长度按完整发送者 ID 缓存，最大消息年龄为 3 轮；新报告覆盖旧报告，包括分裂后变短。同轮精确报告优先，拒绝自身、异队、坏校验和未来消息。
- 献祭接收者仍需当前可见；完整可见身体优先，否则使用可见下限及最新长度消息。旧长度不覆盖新分裂长度，声纳独自不能创建远程献祭目标。
- 后续根据身体跨门、头部仍在落点附近来续报；分裂出的身体也计入当回合占用。
- 占用按 `(portal, sender)` 保存，释放只撤销该发送者的报告。最大消息年龄为 2 轮；过期恢复未知，不证明出口安全。
- 每个发送者只预约一颗近期珍珠。按到达轮次优先，同轮较小 ID 优先。换目标覆盖旧预约，放弃则取消；最大消息年龄为 2 轮。
- 被预约的珍珠从目标选择中让给优先者；所在格子仍可以通行，最后的逃生路线仍可使用。
- 已吃掉的珍珠不会从旧视野再次播报为存在，并发出带原事件轮次的消费报告。珍珠观察消息拒绝超过 3 轮的旧信息，路由也检查缓存年龄。
- 行动 RALLY 最大消息年龄为 1 轮。当前视野发现对应头部不在报告位置，就丢弃该预测。
- 已知队友意图用于计算近期冲突风险；缺少意图时枚举可行的一步移动，唯一出口获得较高保护。
- 占用和预测不修改真实碰撞模型。普通建议保留最后的物理逃生动作；上面的门口紧急避撞规则明确允许短头自杀以保护队友。

## 动作快照与 Echoes

声纳准备发生在最终动作确定以后。模拟自身移动、冲刺长度消耗、可见珍珠消费和分裂；不会编造未知传送门落点或新增视野。
下一步是预测，可能因新视野、队友动作或生存需要而改变。

普通四束 Echoes 只保存合计，不分配到方向，也不当成消息送达确认。
门口优先发送定向等待包，原先的单束未知门探测在该场景让位。不能把等待包发射后的多束总计当成某一门方向的反馈；命中队友也不能推出具体距离或送达对象。

声纳可能丢失、被拦截、回到自身；协作仍依赖接收方当前视野与物理安全检查。
