# V4 生存与开局导航审计

基线：`a4c2067`（Persist opening heading route across detours）。本次按用户要求检查观察、身体记忆、地形/传送门、搜索、任务仲裁、分裂、最终动作保护和执行流程。

## 确认的问题与修复

| 问题 | 证据及处理 |
| --- | --- |
| 开局传送门探索访问空数组 | `openingPriorityAction()` 未初始化 `routeCrowd` 就调用 `scoutTileScore()`。原生内存检查在 dilemma 第 0 轮复现空指针偏移访问。现在初始化存储，并在调用前计算本轮拥挤度。 |
| 第 38 轮有尾部逃生机会却输出空动作 | devil 固定种子下，0 号龙长度 6，最终队友保护把移动变成 NONE；引擎将没有行动判为死亡。增加统一最终动作处理，优先合法分裂或可行移动，禁止软性避让规则直接制造空动作。保留经过专门条件判断的后期主动捐献。 |
| 完全被海草封闭的头未触发开局剥尾 | 原判断额外要求邻格必须出现自己的身体。现在完全海草封闭也算被困；前 20 轮剥尾 2 不要求尾巴可见或能逃生。 |
| 20 轮后尾部未知时放弃救援 | 无合法头部移动时仍尝试合法分裂；尾部逃生有依据时可保留头部 2 节、反向释放后部，其余按剥尾 2 救援。常规扩张仍要求尾部出口可见且空闲。 |
| 出生身体没有加入记忆 | 过去只从第一次头部位置开始记轨迹；连续吃珍珠后，原始尾巴出了视野便丢失。现在补入可见出生身体，并在救援时利用已经记住的身体和地形。原有珍珠走廊回归因此恢复通过。 |
| 导航压过常规扩张，较晚出生的龙又漏掉导航 | 恢复开局扩张入口，所有前 60 轮出生的龙都可执行开局任务。开局任务活动期间，通用分散策略不再抢占路线。 |
| 开局方向与绕障碍距离不一致 | 前三轮记录实际出生朝向，包括与地图长轴垂直的朝向。BugNav 直接行进、绕墙和少量珍珠绕路使用相同的方向距离。长轴只决定中轴线。方向在之后的开局任务中持续保留；发现对应外侧边界封闭才切中心。 |
| 轮次边界及第 0 轮观察状态错误 | 引擎实际输入从 ROUND 0 开始。前三轮为 0–2，前 20 轮为 0–19，前 60 轮为 0–59；“从未看见”的标记改为 -1，避免把第 0 轮看到的格子当成未知。 |
| 传送门落地检查晚一轮，且可能被其他分支跳过 | 在本轮初始化时记录确认过的穿越事件，再检查出口区域。出口检查/返回尚未完成时，主开局导航不会提前解除任务。 |
| 未知传送门背后的脖子被当作出口 | 反向进入紧贴脖子的门，即使远端未知，也不能当作空闲出口。通过真实引擎验证这一点，并保留绕到门另一侧后安全返回的能力。 |
| 多颗珍珠路线低估身体释放时间 | 搜索现在累计吃到的珍珠数量，逐颗延后自己身体的释放时间。 |

## 传送门返回的两个不同情形

使用官方引擎构造两扇竖直门：入口在 `(2,5)` 与 `(3,5)` 之间，另一扇在 `(7,5)` 与 `(8,5)` 之间，龙长度为 2。

- 从 `(2,5)` 向东穿门，落在 `(8,5)`；紧接着向西返回，落点为 `(2,5)`，那里是自己的脖子。引擎判定 `S`（自撞）。
- 穿门后绕 `北、西、南` 到 `(7,5)`，再向东进门，落在 `(3,5)`，返回成功，没有死亡。

因此没有禁止所有“返回传送门”的动作。限制针对反向撞入自己的脖子；一般返回仍由落点和占用情况判断。

规则参考：[传送门](https://game.battlecode.au/docs/kelp-and-portals)、[移动与碰撞](https://game.battlecode.au/docs/movement)。

## 限制

- 这是每张图一个种子的对照，不代表排位或所有种子的长期胜率；本版仍输了 13 场，战斗及不同地图的发育策略仍有改进空间。
- 没有宣称所有死亡都消失。长度不足 4、人口已满且没有合法移动时无法分裂；按要求在头尾都困时剥出的短龙也可能无法存活。后期满足条件的主动捐献依然保留。
- 身体记忆只能补全实际看见或走过的部分；救援对未知尾部保留剥尾 2 的兜底，不假定不可见区域一定空闲。

## 复现

在项目目录执行：

```sh
python3 verification/run_checks.py
python3 verification/protocol_regressions.py --sanitize
python3 verification/portal_roundtrip.py
V4_AUDIT_OUT=/tmp/v4-audit-results python3 verification/audit_matches.py fixed . ../tyhh wasm 500
```

对照旧版可以将 `a4c2067` 导出到独立目录，再把对照脚本的候选路径替换成那个目录。脚本为 C++ 源码创建临时快照，将头文件指纹加入编译单元，避免本机工具链只按 `.cpp` 内容缓存 WASM、忽略头文件修改的问题。
