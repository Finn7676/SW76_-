# 用你的电脑给擂台加算力（队友指南）

> 这份文档发给队友照着做即可。目标：把你电脑的 CPU 接入 Battlecode Arena 的对局池，
> 帮忙一起跑排位对局，让胜率矩阵和 Elo 更快算出来。

## 这是什么？为什么安全？

服务器只有 **2 核**，一轮大循环赛（几十个 bot × 所有地图 × 双方先手）要排很久。
这个小工具（`agent.py`）会：

1. 向服务器**领取**一局待跑的对局（`claim`）；
2. 在你本机用 `unswbc` **跑完**这一局；
3. 把结果和 `.replay` **回传**给服务器（`submit`）。

服务器自己那 2 核也在同时跑，你只是往池子里**额外加 CPU**。几个关键点让这件事**零风险**：

- **引擎是确定性的**：同一局 `(地图, A方bot, B方bot)` 不管在谁的机器上跑，结果都完全一样。所以你跑出来的结果 = 服务器自己跑的结果，不会污染数据。
- **对局是原子领取的**：一局被你领走后别人领不到，绝不会重复跑。
- **中途退出安全**：随时 `Ctrl-C`。你手里没跑完的对局，服务器 15 分钟后会自动重新排队，交给别人（或你重启后）继续。
- **不需要碰服务器**：整个过程只是普通的 HTTP 请求，和你在浏览器登录网站用的是同一套账号密码。

## 一、你需要准备的东西

| 依赖 | 说明 |
| --- | --- |
| **Python 3.9+** | 跑 `agent.py`。只用标准库，不用 `pip install` 任何东西给 agent 本身。 |
| **`unswbc`（版本 `0.3.6`）** | 跑对局的官方工具，**版本必须和服务器一致**，否则结果可能对不上。 |
| **`agent.py`** | 就是这个脚本，见「二、拿到脚本」。 |
| C++ 编译器（**可选**） | 只有当你想跑 **C++ 写的 bot** 时才需要 `g++` / `clang++`。跑 Python bot 完全不用。 |
| **账号密码** | 站点的 basic-auth（和登录网页那套一样）。**问队长（本仓库拥有者）要。** |

> 服务器地址：`http://arena.peop1e.com`（HTTP，80 端口，agent 默认就是它，不用手填）。

### 安装 Python

- **macOS**：一般自带，或 `brew install python`。检查：`python3 --version`。
- **Windows**：去 <https://www.python.org/downloads/> 下载安装，安装时**勾选 “Add Python to PATH”**。检查（PowerShell）：`python --version`。
- **Linux**：`sudo apt install python3`（或对应包管理器）。

### 安装 unswbc（**版本要锁 0.3.6**）

推荐用 `uv`（快、干净）；没有 `uv` 就用 `pip`。二选一：

```bash
# 方式 A：uv（推荐）
#   先装 uv：curl -LsSf https://astral.sh/uv/install.sh | sh   （Windows 见 uv 官网）
uv tool install "unswbc==0.3.6"

# 方式 B：pip
pip install "unswbc==0.3.6"
```

装完**务必核对版本**：

```bash
unswbc --version      # 必须显示 0.3.6
```

> 如果 `unswbc` 提示找不到命令：用 `uv` 装的话它在 `~/.local/bin`，确认这个目录在 PATH 里；
> 或者跑 agent 时用 `--unswbc /完整/路径/unswbc` 指定。

### （可选）C++ 工具链

只有当擂台里有 **C++ bot** 且你想帮忙跑它们时才需要：

- macOS：`xcode-select --install`
- Linux：`sudo apt install g++`（需要支持 C++20，建议 g++-10 及以上）
- Windows：C++ 在 Windows 原生比较麻烦，**建议用 WSL（Ubuntu）**来跑 C++ bot。只跑 Python bot 的话忽略这一步即可。

> 如果你不装 C++ 工具链，遇到 C++ bot 那局会失败并回传一个错误——服务器会重新排给有编译器的机器，**不影响其他对局**，你也不会把数据搞坏。

## 三、跑起来

在 `agent.py` 所在目录执行（把密码换成队长给你的）：

```bash
ARENA_USER=admin ARENA_PASS='队长给的密码' python3 agent.py --concurrency 6
```

Windows PowerShell 里环境变量写法不同：

```powershell
$env:ARENA_USER="admin"; $env:ARENA_PASS="队长给的密码"; python agent.py --concurrency 6
```

**`--concurrency` = 同时跑几局。** 经验值：设成你的 **CPU 核数减 1~2**，给日常使用留点余量。
比如 10 核的 Mac 用 `--concurrency 8`。

启动后你会看到类似输出：

```
[start] 6 workers -> http://arena.peop1e.com (cache: /Users/you/.battlecode-arena-worker)
[game 1423] 12 vs 7 on arena -> A (318r, 2140ms)  [total 1]
[game 1424] 5 vs 19 on Colosseum -> B (401r, 3050ms)  [total 2]
...
```

看到 `[game ...] -> A/B/draw` 不断刷出来，就说明你正在贡献算力了 🎉。
队长也能在网站上看到队列被更快地消化。

**停止**：`Ctrl-C`。手里没跑完的对局会被服务器自动回收重排，不用担心。

> 首次启动时，agent 会**从服务器按需下载**每张用到的地图（官方 + 扩展地图都有），
> 并把每个 bot 版本缓存到 `~/.battlecode-arena-worker/`。版本是不可变的，所以每个只下载一次，
> 之后重复对局直接用缓存，很省流量。

## 四、所有可调参数

命令行参数和环境变量二选一，命令行优先。

| 环境变量 | 命令行 | 默认值 | 含义 |
| --- | --- | --- | --- |
| `ARENA_URL` | `--url` | `http://arena.peop1e.com` | 服务器地址，一般不用改 |
| `ARENA_USER` | `--user` | 无 | basic-auth 用户名（**必填**） |
| `ARENA_PASS` | `--password` | 无 | basic-auth 密码（**必填**） |
| `BC_CONCURRENCY` | `--concurrency` | `6` | 同时跑几局 |
| `BC_UNSWBC` | `--unswbc` | `unswbc` | `unswbc` 可执行文件路径 |
| `BC_GAME_TIMEOUT` | `--timeout` | `300` | 单局超时（秒） |
| `BC_WORKER_DIR` | `--workdir` | `~/.battlecode-arena-worker` | 缓存目录（地图 + bot 版本） |
| — | `--poll-idle` | `3.0` | 队列空时，隔几秒再问一次有没有活 |

例子——用绝对路径的 unswbc、并发 4、缓存放到别处：

```bash
ARENA_USER=admin ARENA_PASS='...' \
  python3 agent.py --concurrency 4 \
  --unswbc ~/.local/bin/unswbc \
  --workdir /tmp/bc-cache
```

## 五、让它在后台长时间跑（可选）

跑一次大循环赛可能要很久，你可能想挂后台、关掉终端也不停。

**macOS / Linux — 用 `nohup`：**

```bash
ARENA_USER=admin ARENA_PASS='...' \
  nohup python3 agent.py --concurrency 6 > ~/bc-worker.log 2>&1 &
# 看日志：tail -f ~/bc-worker.log
# 停止：  找到进程 pkill -f agent.py
```

**用 `tmux` / `screen`（更好，能随时回来看）：**

```bash
tmux new -s bcworker
# 在里面正常跑 agent.py，然后按 Ctrl-b 再按 d 脱离
# 回来看：tmux attach -t bcworker
```

> 想跑就跑、不想跑就 `Ctrl-C`，非常随意。不需要一直开着，帮多少算多少。

## 六、遇到问题怎么办

| 现象 | 原因 / 解决 |
| --- | --- |
| `error: set ARENA_USER and ARENA_PASS` | 没设账号密码。按「三、跑起来」的写法带上。 |
| `[claim] HTTP 401` 或 `403`，然后自动停止 | 账号或密码错了。找队长核对（注意密码里的特殊字符，建议整段用单引号 `'...'` 包住）。 |
| `error: 'unswbc' not found on PATH` | 没装或不在 PATH。重看「安装 unswbc」，或用 `--unswbc /完整路径`。 |
| `unswbc --version` 不是 `0.3.6` | 版本不一致。重装并锁版本：`uv tool install "unswbc==0.3.6"`（或 pip 同理）。 |
| 某些 `[game ...] ERROR: ... build error` | 多半是 C++ bot 而你没装编译器。装 C++ 工具链，或忽略——服务器会把这局重排给别人。 |
| `[claim] <网络错误>`，隔几秒重试 | 网络抖动或服务器重启，agent 会自动重连，通常不用管。 |
| 首次启动卡在下载 | 在下载地图 / bot，稍等；之后走缓存就快了。 |
| 想清空缓存重来 | 删掉缓存目录 `~/.battlecode-arena-worker/` 即可，会重新下载。 |

## 七、常见疑问（FAQ）

**Q：会不会把服务器数据搞乱？**
不会。引擎确定性 + 对局原子领取，你跑出来的结果和服务器自己跑的一模一样，且绝不会重复计。

**Q：会占我多少资源 / 网络？**
CPU 由 `--concurrency` 控制，自己定。网络很小：每个 bot 版本和地图只下载一次并缓存，之后基本只有回传结果和 `.replay`（每局约 1 MB 量级）。

**Q：我关机 / 断网 / Ctrl-C 了会怎样？**
你手里没跑完的那几局，服务器约 15 分钟后自动重新排队交给别人。已经回传的结果不受影响。

**Q：需要我改代码或碰服务器吗？**
不需要。你只跑 `agent.py` 这个客户端，其它什么都不用动。

**Q：我的 bot 源码会泄露吗？**
agent 会从服务器下载参赛 bot 的项目来跑（这是擂台内部工具，大家的 bot 本来就在同一个平台上互相对战）。缓存只在你本机 `~/.battlecode-arena-worker/`。
