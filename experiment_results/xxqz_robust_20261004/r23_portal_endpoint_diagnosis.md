## Decision Boundary

Two actual H14 friendly incoming-portal queen deaths support the existence of this failure mode, but only one has a complete-visible same-length ordinary alternative, and it occurs in a win. The only loss witness fails the proposed completeness gate. This is enough to motivate a narrowly scoped source fixture; it is weak evidence for broad expected win-rate benefit. The first implementation should not relax body completeness, invent remote friendly intent, or add a map/ID-specific exception to cover trauma.

A possible isolated policy reviews an already living ordinary queen move whose final head has a currently shown portal edge, directly selecting a known ordinary, same-length, nonportal endpoint alternative with proved continuation and existing hard/soft friendly gates. Preserve split/donation/portal/unknown proposals and preserve the original when no proved replacement exists. A generic score penalty followed by the original fallback is not an equivalent safety-constrained mechanism. No candidate was implemented in this diagnostic task.

Initial preturn position events that repeat map head/tail are not counted as body growth; every final standing was reconstructed and matched the audited replay. Inputs were not regenerated by an engine: current vision is the official radius3 around the queen before its recorded previous action, with all tile edges in that view. Alternatives are ordinary, same projected length, living and continuation-proven, not global enemy/friend safety certificates.
