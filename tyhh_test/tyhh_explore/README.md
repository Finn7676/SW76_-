# tyhh_explore

这是针对建议 11 的单变量测试版本，基线为当前 `tyhh`。

## 变化

- 将部分龙按 `dragon_id % 4 >= 2` 设为探索龙；
- 探索龙优先把局部地图前沿作为目标，而不是优先追逐珍珠；
- 对未探索格、邻域开放度和探索路径提高评分；
- 探索龙达到长度 6 且有至少两个安全方向时分裂，生成新的信息头；
- 非探索龙仍保留基线的珍珠和生存评分。

该版本只改变探索角色、信息收益和探索龙分裂策略，不加入密度抑制或旗舰保护。

## 验证指标

- `scout-frontier` 指标出现次数；
- 分裂次数和分裂时地图已见格比例；
- 终局已见格数量；
- 珍珠获取数、平均长度和最长存活龙长度；
- 自撞、撞龙和头部相撞次数。
