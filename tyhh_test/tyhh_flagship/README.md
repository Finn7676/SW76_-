# tyhh_flagship

这是针对建议 13 的单变量测试版本，基线为当前 `tyhh`。

## 变化

- 将 `dragon_id % 4 == 0` 的龙设为旗舰候选；
- 旗舰候选提高邻域开放度权重，降低单纯吃珠权重；
- 旗舰候选更强地规避敌方头部风险、未知路径和局部死胡同；
- 旗舰候选不主动分裂；
- 非旗舰龙保留原有扩张和分裂逻辑。

由于每条龙运行独立程序，当前版本使用确定性 ID 角色近似旗舰分工，尚未通过声呐同步真实队伍最长龙。因此该版本用于验证“保护型角色”是否比所有单位使用相同策略更稳定。

## 验证指标

- ID 角色为旗舰候选的最长存活长度；
- 500 回合时的最长龙和总长度；
- 旗舰候选死亡回合；
- 头部相撞、撞身体和自撞数量；
- 胜率及按长度结束的胜负差。

## 初步实验

使用 `xxqz_cpp` 作为对手，每张地图 2 局，双方各作为 Team A 和 Team B：

| 地图组 | 胜负 | 胜率 |
|---|---:|---:|
| `big_empty`、`help`、`default` | 3-3 | 50.0% |
| `arena`、`Colosseum`、`default_small` | 3-3 | 50.0% |

日志目录：`replays/20260922-111828-mekepivr`、`replays/20260922-112556-w2qy2mht`。该版本出现明显阵营差异：小地图 3 局 Team A 全部失败、3 局 Team B 全部获胜，说明仅按 `dragon_id mod 4` 固定旗舰角色会把行动顺序和出生位置偏差固化，不能直接作为最终策略。
