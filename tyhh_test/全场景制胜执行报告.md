# 全场景制胜方案执行报告

## 执行范围

已严格在 `tyhh_test` 中按 [全场景制胜方案.md](./全场景制胜方案.md) 的 M0→M14 顺序建立独立版本。每个阶段只在上一个候选副本上增加一个机制；`tyhh/` 和用户已有 `tyhh_test` 实验目录没有被覆盖。

最终候选代码位于 `tyhh_test/tyhh_plan_final`，来源为 M12。严格编译命令为：

```bash
clang++ -std=c++20 -O2 -Wall -Wextra -Wpedantic -Werror \
  tyhh_test/tyhh_plan_final/main.cpp -o /tmp/tyhh_plan_final
```

## 结论与下一步

方案已经完成 M0 到 M14 的逐步实现和验证，但最终验收门槛没有通过：实验版没有在全部场景击败 Version04，也没有解决 `big_empty` 与 `help`。因此本次不把 `tyhh_plan_final` 同步到主 `tyhh`。

最明确的失败信号是：M6 声呐珍珠目标在开发集下降到 1/8，M13 固定式动态旗舰保护没有改善，M14 只提高 64×64 图的开放空间权重仍未击败 Version04。后续若继续，应优先针对 `help` 的高人口碰撞和 `big_empty` 的单位扩张节奏做独立机制实验，并为每个候选至少运行双方各 10 局后再决策。
